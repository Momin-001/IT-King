# IT King

## Setup & Installation

Follow the steps below to install dependencies and start the development servers.

### 1. Install backend dependencies

```bash
npm i
```

### 2. Change DB connection string

```
open .env file
Change DATABASE_URL to match your local DB
```

### 3. Run backend

```bash
npm run dev
```

### 4. Navigate to Frontend

```bash
cd frontend
```

### 5. Install Frontend dependencies

```bash
npm i
```

### 6. Run Frontend

```bash
npm run dev
```
