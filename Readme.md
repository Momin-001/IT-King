# IT King

## Setup & Installation

Follow the steps below to install dependencies and start the development servers.

### 1. Install backend dependencies

```bash
npm i
```

### 2. Run backend

```bash
npm run dev
```

### 3. Navigate to Frontend

```bash
cd frontend
```

### 4. Install Frontend dependencies

```bash
npm i
```

### 5. Run Frontend

```bash
npm run dev
```
